# Race catalog seed list

The races the `/races` page ships with (B13, PR 20). This list says which races to include. Facts like the usual month are a starting point only: PR 20 checks every entry (date pattern, start time of the main wave, timezone, exact distance) against the race's official website and records the month it was checked in `verified`. GPX files come later, exported from Strava and added with `pnpm races:add`.
